Welcome to issue no. 1.

The old version of this website was a terminal. You typed commands into it and
it pretended to be a 1970s mainframe, which was fun for about a week in 2019
and then just became furniture. So I tore it out and rebuilt the place as
something else: a photocopied zine.

Here's the pitch. The web doesn't have to look like a dashboard. It can look
like something that came off a risograph in the back of a bike shop — two inks,
a bit of grain, layers that don't quite line up. That's this site. Cream paper,
orange and blue ink, crop marks in the corners, an issue number on the cover.

> Imperfection is a feature. The misregistration is the message.

What goes in it? Essays and notes about the things I actually make — apps,
simulators, mods, e-paper gadgets — plus whatever I'm thinking about that
week. Short, opinionated, first person. No listicles, no "10 tips", no
"in today's fast-paced world".

New posts land here, newest first, and there's an [RSS feed](/rss.xml) for
the old-school among you.

The whole thing is one static build. View source if you want to see how the
ink dries:

```bash
npm ci && npm run build   # that's the entire printing press
```

More soon. — J.
